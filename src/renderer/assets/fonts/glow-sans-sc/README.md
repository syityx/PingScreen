# Glow Sans SC Normal

配置页内置未来荧黑 SC 标准宽度版，来自作者官方发布 v0.93：
https://github.com/welai/glow-sans/releases/tag/v0.93

下载资产：`GlowSansSC-Normal-v0.93.zip`。保留原始字体文件及其名称，未裁剪字库或修改字形。

| 文件 | OS/2 原生字重 | CSS 字重 |
| --- | --- | --- |
| GlowSansSC-Normal-Regular.otf | 400 | 400 |
| GlowSansSC-Normal-Book.otf | 500 | 500 |
| GlowSansSC-Normal-Medium.otf | 600 | 600 |

使用字体内实际的 OS/2 字重，避免仅凭文件中的英文名称推断字重。仅设置页选择该字体，回答卡片与轮盘的字体规则保持原样。

字体采用 SIL Open Font License 1.1。许可原文见同目录 `OFL.txt`，应用分发的 `THIRD_PARTY_LICENSES.txt` 也包含该许可全文。
