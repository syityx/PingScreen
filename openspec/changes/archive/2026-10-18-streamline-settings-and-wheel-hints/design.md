# Design

## Context

动机和已确认范围见 proposal.md。当前 `Settings.tsx` 将四个分类排在同一滚动容器中，侧栏是锚点导航；已有模型草稿、串行自动保存和滚动位置追踪。样式同时使用 `scroll-behavior:smooth` 与 `scroll-snap-type:y proximity`，`navigate()` 调用原生平滑滚动，手动操作只释放分类高亮锁，没有明确停止动画的生命周期。

`src/main/index.ts` 当前为设置窗口使用最多 1000 × 900 的初始尺寸，允许移动和缩放，未声明最小尺寸。侧栏默认宽 210px，850px 断点缩到 180px；640px 以下改为顶部导航。700px 最小窗口配合更大的文字，需要专门验证表单换行。

`Stage` 的 `stage-hint` 共用于手势轮盘、框选和框选后选意图；`wheel-caption` 则提供轮盘附近的当前意图和翻译范围。两者不可一并按“说明文字”删除。

现有 smoke 明确要求滚动吸附、读取自动保存成功文字、验证侧栏文字，并有模型连接与字号草稿隔离检查。这些检查需要按本次新契约调整，业务隔离检查继续保留。已完成但未归档的 `add-cloud-provider-presets` 是当前实现基线，本次不修改其文档或服务商目录契约；主规格 `answer-reading` 无需修改。

## Goals / Non-Goals

**Goals:** 用局部 UI 状态和样式调整实现需求；将侧栏导航动画与用户原生滚动明确分开；让最小窗口在放大字号后仍可完整配置。

**Non-Goals:** 不引入分页式设置、第三方滚动库、全局字号缩放、新的设置持久化字段或数据迁移；不修改回答卡片和原生手势识别。侧栏跨重启记忆未获确认，本次不纳入。

## Decisions

### 1. 按用途精简文案，保持反馈通道

在 `Settings.tsx` 删除普通配置项解释、分类副标题和已确认的说明卡片。相较仅用 CSS 隐藏，直接删除冗余呈现可以避免留下无意义的语义节点与空白占位。以下清单是对已确认精简原则的实施归类：

| 区域 | 处理 |
| --- | --- |
| 分类标题下宣传语、普通配置行的解释 | 删除，保留标题和操作控件 |
| 蓝色 Note 三块、安全说明卡片 | 删除界面节点；隐私和数据处理资料继续由现有 README 承载 |
| 轮盘布局中的重复布局解释、取消步骤及内部定位原理 | 删除常驻解释，保留布局按钮、预览和当前选择 |
| 模型区重复的“连接你的多模态模型”、通用接口解释和测试说明 | 按同一精简原则收紧，保留模型连接分类标题及字段 |
| API Key 字段旁重复提示 | 合并到现有输入框状态提示，保留留空保留、待清除和未配置三种含义 |
| 服务商地域、模型／部署 ID 等与正确填写有关的信息 | 不能当作宣传文案直接清空；仅保留必要差异并简写，通用兼容协议描述可移除 |
| 自动保存普通／进行中／成功文字 | 不渲染，仅失败时展示错误；不取消自动保存与失败回退 |
| 状态栏操作说明与“开启／关闭” | 删除；状态名、开关及启动失败处理提示保留 |
| 模型显式保存、测试结果、密钥未保存警告、真实错误 | 保留按需反馈；不将所有成功反馈一律隐藏 |
| 展开侧栏的品牌、快捷键、版本，底部关于与版权 | 保留；收起侧栏时文字区域隐藏，不从产品中删除 |

不引入新的帮助中心或大段替代提示。自动保存失败继续通过可访问的状态区域呈现；修复后再次成功保存时消除旧失败提示，不显示成功占位。

### 2. 字号限定在设置页，紧凑来自间距

字体选型已由用户确认：配置页采用未来荧黑 SC 标准宽度版，随应用内置 v0.93 原始 OTF，不依赖用户安装或远程字体服务。按字体文件 OS/2 字重映射 Regular=400、Book=500、Medium=600，不按英文文件名猜测字重。通过设置页作用域选择字体，保留原有回答卡片与轮盘字体规则；许可原文保留在字体资源目录，并完整附入分发文件 THIRD_PARTY_LICENSES.txt。构建时由现有 Vite 资源流程输出字体，不引入新依赖。

将配置行标题、字段标签、输入框、下拉框及其选项设为 15px，分类标题 20px；配置数值及相关操作保持协调大小，次要归属信息继续较小。采用设置页作用域选择器，避免影响回答字号和轮盘。

普通配置行尽量单行，窄空间允许控件分行；模型表单使用可收缩的布局，长服务商名、模型 ID、错误内容允许适当换行。减少面板内边距与分类间距，不使用整页缩放，也不为分类保留整屏最小高度。

验收修正：单行配置项必须统一外框高度并垂直居中。采用共享的 56px 最小行高，下拉控件明确为 36px，避免原生控件的自然高度撑出不同的行高；移除窄窗口下滑块额外的 40px 缩进。正常状态栏沿用同一最小行高；多行内容与异常状态仍可自然增高，不使用固定高度截断。

后续视觉修正：用户要求整体提升观感，单纯等高不足以满足验收。手势、应用的同类单行项合并到同一圆角分组内，以细分隔线分行；白色侧栏与浅灰内容底区分导航和设置区域，统一控件边框、圆角、焦点和留白。品牌和收起按钮并排，正常运行状态合并至顶栏右侧；轮盘布局选项使用浅灰容器中的分段按钮，并收小预览以减少空白。保留 15px／20px 字号、56px 行高、已有窗口尺寸和交互契约。具体视觉效果仍需用户确认，不因自动检查通过而视为审美验收通过。

**建议实施起点，非用户确认的精确数值：** 主内容内边距约 16px、面板约 12px、普通行约 8–10px 垂直内边距、分类间可见间隔约 16–24px。以 15px 文字不拥挤、不重叠为准调节，不把这些建议写成固定产品验收值。

### 3. 只调整设置窗口的几何约束

在 `createWindow` 的设置分支指定初始 900 × 560、最小 700 × 400；保留 `resizable`、`movable` 及原生窗口框架。相较给所有窗口统一参数，按角色设置可避免破坏全屏 Stage 和内容驱动的回答卡片。

尺寸沿用现有 Electron 窗口外框的逻辑像素语义，不等同于扣除标题栏后的网页视口。新建窗口默认使用该初始尺寸；不新增尺寸记忆。对于工作区小于默认尺寸但仍容纳最小尺寸的情况，沿用当前按工作区约束初始尺寸的做法。小于 700 × 400 的异常工作区不自动降低已确认的最小尺寸，本次不增加新的特殊适配契约。

### 4. 使用局部侧栏状态，折叠不卸载页面

在 `Settings.tsx` 增加局部展开状态，新建设置页默认展开；收起／展开按钮放在侧栏顶部且两种状态都可见，使用现有图标体系，具有可访问名称和展开状态。折叠只是调整侧栏宽度及隐藏文字，不卸载导航或表单，因而不会丢失模型草稿。

收起时保留品牌图标、分类图标及当前分类高亮，隐藏分类文字、品牌文案和底部文字，悬停分类图标显示名称；可使用原生提示配合 `aria-label`，无需新增提示库。键盘焦点样式和分类名称不能随文字隐藏而消失。

建议展开栏沿用约 180–210px，收起栏约 60–64px；具体宽度为实现参数。700px 宽下仍保留用户主动选择的展开／收起状态，不新增自动折叠规则。收起及窗口缩放时终止尚未完成的导航，按布局变化后的分类锚点保持阅读位置并重新计算高亮。

### 5. 取消吸附，导航动画显式可取消

保留连续页面，移除设置容器的分类吸附。容器常规滚动使用原生行为，不拦截滚轮来模拟惯性；只对侧栏发起的导航播放动画。相较依赖全局 `scroll-behavior:smooth`，一个可取消的 `requestAnimationFrame` 导航能明确处理新目标覆盖和用户中断，避免停止指令又被平滑样式延迟。

导航保存当前动画句柄、最新目标与分类选择锁。点击分类从当前 `scrollTop` 开始，目标限制在有效滚动范围；新点击先取消旧句柄，再重新计算目标。每帧只更新滚动位置，不逐帧更新整页 React 状态。系统减少动态效果时立即定位。

用户滚轮／触控板、触摸、滚动条拖动或页面滚动键输入立即取消导航并释放选择锁。滚动键只在页面滚动上下文中处理，不夺走输入框、下拉框或文本编辑的按键。卸载和布局变化同样清理动画与监听器，延迟回调不得继续修改旧目标。

高亮沿用现有按帧节流的分类位置判定。程序导航途中锁定最新点击分类，避免途经分类闪烁；末尾短分类可能共享同一滚动终点，继续保留其点击选择直到用户接管，不能一到页面底部就把其他目标错误改成“应用”。手动阅读时由实际位置决定高亮。

**建议实施起点，非用户确认的精确时长：** 导航约 180–280ms、平滑减速、不回弹；最终以连续点击和手动打断的验收表现为准。侧栏不额外增加复杂装饰动画。

### 6. 顶部提示按轮盘可见状态移除

对 Stage 的 `wheel` 和 `regionIntent` 状态隐藏 `stage-hint`，保留独立 `region` 框选过程现有提示。这是按“触发轮盘后的顶部说明”解释的保守边界，不将精简扩大到用户未讨论的全部框选反馈。

保留 `wheel-caption`、扇区、翻译点／条范围、可访问标签与原有命令处理，不改变原生输入助手和截图上下文。只清理确实无剩余引用的样式，避免因共用选择器影响框选提示。

## Risks / Trade-offs

- [15px 文字配合 700px 窗口可能挤压表单] → 在默认／最小尺寸和侧栏两种状态检查自定义连接、长服务商名、手动模型 ID 和错误内容；空间不足时换行。
- [滚动动画和 ResizeObserver 互相干扰] → 统一取消入口；折叠及缩放时重新计算锚点，不让旧目标或回调继续运行。
- [精简误删必要反馈或密钥状态] → 按上述清单分类，复用现有保存、草稿、错误回退和密钥隔离验证。
- [旧 smoke 将吸附或成功文字视为正确行为] → 修改对应断言，新增可打断及最新目标优先验证，不仅更新截图。
- [模拟滚动无法完整体现实际手感] → 自动检查行为边界，人工用鼠标和触控板验收跟手性、短跳转及视觉密度。

## Migration Plan

仅调整界面和窗口参数，无设置格式迁移。实现后运行类型检查、现有单元测试、构建及 Electron smoke；在 900 × 560 和 700 × 400、侧栏展开／收起及常用 Windows 缩放下人工验收。回退时恢复界面与窗口改动即可，不要求恢复配置备份。本次提案不执行这些实现或测试任务。

## Open Questions

以下仅影响细节调校，不是未解决的关键方案，也不作为已确认需求：

- 导航精确时长与缓动曲线、侧栏宽度、面板和分类间距：采用上述建议起点，由实际视觉验收调校。
- 用户没有要求跨重启记忆侧栏状态；本次默认不增加持久化。若以后需要记忆，应另行确认范围。
