# 0.1.8 正式版验证记录

日期：2026-10-20。功能分支：`codex/customize-wheel-actions`。正式标签：`v0.1.8`。

## 功能与规格

- 四／五／六项轮盘共用六槽位顺序，支持多个独立名称、内置图标和提示词。
- 二级及三级编辑页占满同一窗口、隐藏主导航；拖动排序平滑换位，预览跨页移动与缩放。
- 编辑按钮触发聚焦菜单，三级输入框保持中性边框；二级页统一手动保存并保护未保存退出。
- 自定义任务沿用截图、定位、模型传输与会话语义；提问、翻译和框选保持各自行为。
- `customize-wheel-actions` 的 24 项任务完成，四份增量规格同步后逐项比对，五份主规格严格校验通过；归档至 `openspec/changes/archive/2026-10-20-customize-wheel-actions`。

## 验证

- 0.1.8 类型检查通过；8 个文件、73 项应用测试通过。
- 完整 Electron smoke 通过，覆盖原生鼠标排序、键盘排序、自动滚动、取消、全窗口编辑、聚焦边框、草稿保存和窗口关闭保护；详见 [轮盘编辑验证](2026-10-20-wheel-editor-redesign.md)。
- 独立构建目录全新安装依赖，430 项原生逻辑测试及 11 项颜色测试通过，避免覆盖运行中的开发助手。
- 版本在 package.json、锁文件、README、更新记录和中文使用说明中保持一致。

## 发布方式与边界

正式版本由 GitHub 的 `v0.1.8` 标签工作流重新构建、检查并发布 Windows x64 安装程序、blockmap 和 SHA-256 校验文件。本地验证包不作为云端正式发布产物。

模型网络使用本地模拟接口验证，未使用真实付费模型或用户密钥；多显示器、不同 DPI、HDR 和受保护应用截图未在本次重新验收。沿用现有未签名 Windows 安装程序。

本地正式安装包检查通过：当前代码及原生助手一致，103 个运行依赖许可、Electron／Chromium 声明和中文说明完整；NSIS 安装程序通过完整性校验，已生成安装程序与 blockmap 的 SHA-256 文件。
