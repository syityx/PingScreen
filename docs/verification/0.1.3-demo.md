# pingscreen 0.1.3 UI Demo 验证记录

验证日期：2026-10-14。环境：Windows 11 x64，Electron 44.7.0。

## 设计来源

用户提供的 PingScreen-assets.zip、同目录设置预览和回答卡片预览。白色主题、蓝色强调、图标与轮盘几何沿用提供的设计。字体使用 Inter / Noto Sans SC，缺失时回退至 Windows 系统字体，不联网下载。

## 已验证

- 类型检查通过，37 项应用测试通过。
- Electron 模拟服务完整流程通过，保持点选、框选、自定义提问、追问、停止与取消。
- 设置三页与顶部暂停／恢复开关，以及 500 px 窄窗口布局检查通过。
- 回答卡片完成、生成、错误、停止、自定义提问、展开截图等状态已渲染并检查。
- 五项轮盘与框选后的四项轮盘使用本地 SVG 图标，内部无文字；翻译点／条提示可切换。
- 模型请求沿用原截图与原坐标；1000 次同扇区移动不增加无效界面更新。
- 截图和请求测试使用生成画面与本地模拟服务，未读取真实模型密钥或调用付费模型。
- ZIP 构建通过，压缩包实测 137.2 MiB，共 24 项文件，包含主程序、两个原生助手与中文说明；原生助手与当前构建的 SHA256 一致，截图助手启动后可正常退出。
- 打包元数据确认 demo 标记为 true，主进程包含独立设置目录创建逻辑，归档未包含测试配置或会话截图。

## Demo 分发

只生成 Windows x64 ZIP，不生成 0.1.3 安装程序。解压后运行 pingscreen.exe；同目录包含 DEMO-使用说明.txt。Demo 的模型设置及缓存位于 %APPDATA%\pingscreen-demo，应用标识为 com.pingscreen.demo。开机启动注册项独立命名，不覆盖正式版同名项。

启动前需在托盘退出旧版，避免两个版本同时识别手势。首次启动需在 Demo 中配置模型。
