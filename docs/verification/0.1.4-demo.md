# pingscreen 0.1.4 UI Demo 验证记录

验证日期：2026-10-14。Windows 11 x64，Electron 44.7.0。

- TypeScript 检查及 37 项应用测试通过。
- Electron 完整模拟流程通过，原有手势、点／条翻译、框选、自定义问题、回答、追问、停止与取消保持正常。
- 原生窗口检查确认菜单栏不可见。
- 四个设置部分同时保留在页面中，点击左侧导航可平滑定位到目标顶部；自动高亮与滚动位置一致。
- 注入鼠标滚轮输入，验证在部分边界附近停下时吸附到对应位置。
- 检查直接滚动后的左侧高亮、跨部分设置草稿保留、500 px 窄窗口布局与版权声明可滚动到达。
- 桌面及窄窗口的版权下方间距不超过 17 px；在底部继续注入向下滚轮，位置仍为最大滚动值，无额外留白。
- 模型区操作按钮精确为「测试连接」「保存」；本地模拟服务验证未保存模型与虚拟密钥可测试，测试不持久化，点击保存才写入。
- 验证快速修改阈值、触发键、开机启动与四／五项轮盘自动保存；模型草稿无效时，其他设置仍能保存，且不会存储或覆盖模型草稿。
- 注入设置保存失败，验证自动保存失败提示及对应字段回退。模拟服务和故障注入均未使用真实密钥。
- 配置页尊重系统减少动态效果的偏好；内容超过一屏时仍可自由滚动，不强制逐屏翻页。
- 版权声明包含 pingscreen MIT 协议及 lolPing 原作者 Danrui Meng 的版权信息，保留原许可证文件。
- 紧凑布局检查：所有部分均按内容高度排列，相邻部分内容到标题间距不超过 33 px；应用介绍只有版本与平台两行，重复会话说明已移除。
- 验证点击底部 lolPing 链接通过主进程打开 `https://github.com/darrenprx/lolPing`（测试替换系统打开方法，未实际启动浏览器）。紧凑布局下轮盘与应用可能共用终点，点击仍保留对应导航高亮，手动滚动后恢复自动高亮。

仅生成 Windows x64 Demo ZIP，使用 %APPDATA%\pingscreen-demo 独立设置目录，不生成安装包。测试使用生成画面和本地模拟服务，未使用用户实际模型密钥。

最终 Demo 已重新构建：`release/demo/pingscreen-Demo-0.1.4.zip`（约 137.3 MiB）。检查压缩包可读取，包含主程序、两个原生助手和更新后的中文说明；包内应用归档哈希与已验证的构建一致，包含独立测试／保存、自动保存和底部边界规则。
