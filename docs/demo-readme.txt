pingscreen 0.1.5 · UI Demo · Windows x64

解压整个压缩包到任意文件夹，双击 pingscreen.exe。无需安装。
启动前请先在系统托盘退出旧版 pingscreen，避免两个版本同时识别手势。

Demo 使用独立设置目录：%APPDATA%\pingscreen-demo
首次启动请在“模型连接”填写支持图片输入的服务地址、模型名称和 API Key。
点击“测试连接”检查当前填写内容，测试不会自动保存；点击“保存”才会保存模型配置。
它不会修改已安装版本的模型设置或替换原程序。

测试重点
1. 模型连接 / 手势 / 轮盘 / 应用 连续配置页，以及顶部暂停与恢复开关。
2. Alt + 左键拖动，五项图标轮盘、方向高亮、中心 / Esc / 右键取消。
3. 翻译扇区滚轮切换“点 / 条”；只改变模型提示词，起手位置保持不变。
4. 框选后的四项轮盘、自定义提问、流式回答、停止、失败重试。
5. 回答卡片展开截图、复制、追问，缩小设置窗口后滚动使用。
6. 滚动时左侧自动高亮；停在部分边界附近会轻度吸附；点击左侧导航可平滑定位。
7. 顶部菜单栏已移除，配置页最下方包含 MIT 协议和基于 lolPing 的版权声明，到底部后不会继续滚出空白。
8. 手势、轮盘和开机启动修改后立即保存；模型区仅保留“测试连接”和“保存”两个独立操作。
9. 配置各部分紧凑衔接，应用介绍仅显示版本与平台；底部“基于 lolPing 开源项目”可点击打开 GitHub 仓库。

默认解释为中文，翻译为中文，改写保持原文语言。
实际回答需要你配置的模型服务；Demo 不含密钥、账户或固定示例回答。
每次请求会发送目标所在显示器的完整截图、定位信息和局部细节图。
截图与对话只保留在当前会话，关闭回答或重新标点会释放。

关闭设置窗口后仍驻留托盘；退出请在托盘图标上右键选择“退出”。
Ctrl + Alt + P 暂停 / 恢复。Enter 发送，Shift + Enter 换行。
