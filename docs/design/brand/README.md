# 产品 Logo

`logo-source.png` 是用户于 2026-10-14 选定的原始透明 PNG，按原文件保存。产品使用蓝色 P 定位图形与 ing 字样组合，保持原有形状、颜色及纹理。

运行 `npm run build:brand` 生成界面 PNG、应用 PNG、托盘 PNG 与多尺寸 Windows ICO。处理仅整理外侧透明留白并缩放、转换格式，不重新绘制设计。

界面品牌图形通过图片显示，保留原图颜色，不使用单色 CSS 遮罩。其他功能图标继续采用现有图标。

新 Logo 随 0.1.6 正式版通过 GitHub 构建发布；旧版本标签保持原有源码。CI 与发布任务均重新生成图片，并验证归档中的界面、应用与托盘图片。

验证：原图字节与附件一致；界面 PNG、512 px 应用 PNG、32 px 托盘 PNG 及九种 ICO 尺寸有效；类型检查与 Electron 完整模拟流程通过，桌面及窄窗口品牌图片正常显示。
