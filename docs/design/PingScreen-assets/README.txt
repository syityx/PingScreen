PingScreen 白色主题素材

实际项目：D:\Code\pingscreen，版本 0.1.2

icons/：25 个原创 SVG 图标与 48×48 透明 PNG。描边 1.6 px。
wheels/：5 个轮盘状态 SVG 与 512×512 透明 PNG。
design-tokens.json：颜色、间距、圆角、字体与轮盘几何。
SVG 保留矢量路径，PNG 可直接用于开发。轮盘内无文字。翻译图标右侧用一个小滚轮图标表示可切换模式；中心用关闭图标表示取消。框选四项轮盘不含滚轮提示。

交互规则
1. 五项从顶部顺时针：解释、翻译、改写、提问、框选。四项移除框选。
2. 按住 Alt + 左键拖动；移动超过阈值显示轮盘，松开提交。默认 8 px。
3. 中心松开、Esc、右键或提前松开触发键取消；Alt + 单击不提交。
4. 翻译扇区中，滚轮切换点 / 条。新手势默认点；追问沿用当前模式。
5. 框选在冻结画面上完成，再点击四项意图轮盘。框选仍发送目标显示器整屏上下文。
6. 自定义提问先打开输入卡片。回答可复制、追问、停止、重试。
7. 追问沿用同一截图。新手势替换会话，关闭释放内存，不保存对话历史。

本设计基于 pingscreen，不包含 lolPing 的游戏信号、表情或房间功能。
