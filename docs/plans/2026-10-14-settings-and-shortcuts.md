# 设置与快捷操作开发计划

**日期：** 2026-10-14  
**状态：** 待开发  
**目标版本：** 待定

让轮盘和回答更适合个人阅读习惯，并减少日常使用中的操作步骤。

## 轮盘大小配置

- [ ] 在设置中增加轮盘大小调整，支持恢复默认大小。
- [ ] 缩放后，图标、扇区和鼠标选择范围保持一致。
- [ ] 检查屏幕边缘、四项与五项轮盘，以及不同显示器缩放比例下的表现。

## 回答页面字号控制

- [ ] 提供回答字号调整，支持恢复默认字号。
- [ ] 正文、列表和代码随字号调整，长回答仍可正常阅读和滚动。
- [ ] 检查较大字号和窄窗口下的排版。

## 检查更新

- [ ] 在应用设置中增加「检查更新」入口。
- [ ] 显示当前版本、是否有新版本，并提供更新说明和下载入口。
- [ ] 检查失败时显示简短提示，允许重试。
- [ ] 验证更新后保留已有模型和手势设置。

## 1-ping 模式

开启后，在目标上按 **Alt + 鼠标左键单击** 即可触发，无需拖出轮盘。

- [ ] 增加 1-ping 模式开关，关闭时保持现有 Alt + 单击行为。
- [ ] 确定单击触发的默认任务，以及是否允许用户选择该任务。
- [ ] 以单击位置作为目标，沿用截图、回答和追问流程。
- [ ] 保留拖动轮盘选择意图的操作，验证单击与拖动能正确区分。
- [ ] 检查暂停状态、连续点击和与其他应用快捷操作冲突的情况。

## 烟花彩蛋

在 pingscreen 自身界面中 ping 时，仅在触发位置播放烟花动画。

- [ ] 增加烟花彩蛋，动画结束后自动消失。
- [ ] 彩蛋仅播放动画，不截图、不请求 AI、不创建新的回答会话。
- [ ] 验证软件内的正常操作，以及在其他应用中标点提问的流程。

## 验收

- 轮盘大小、回答字号和 1-ping 开关在重启后保留。
- 常见窗口大小和显示器缩放比例下，内容可读、操作准确。
- 完成后补充对应版本的变化与验证记录。
