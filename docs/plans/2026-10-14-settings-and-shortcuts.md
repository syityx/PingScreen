# 设置与快捷操作开发计划

**日期：** 2026-10-14  
**状态：** 回答字号已实现于开发工作区，其余待开发

**目标版本：** 待定

让轮盘和回答更适合个人阅读习惯，并减少日常使用中的操作步骤。

## 轮盘大小配置

- [ ] 在设置中增加轮盘大小调整，支持恢复默认大小。
- [ ] 缩放后，图标、扇区和鼠标选择范围保持一致。
- [ ] 检查屏幕边缘、四项与五项轮盘，以及不同显示器缩放比例下的表现。

## 回答页面字号控制

- [x] 在“应用”设置提供回答字号滑块，默认 16px，范围 14–24px，步长 1px，自动保存并在下次回答生效；需要默认大小时可将滑块调回 16px。
- 独立“恢复默认”按钮和字号预览尚未纳入本次范围。
- [x] 正文、列表、标题、代码和表格随字号调整，长回答仍可正常阅读和滚动。
- [x] 检查 14px、16px、24px 与 640 × 400、480 × 300、320 × 200 横向卡片的排版，完成 27 组渲染组合；真实桌面高 DPI 手动测试见专项验证记录。

实现与验证见 [回答阅读体验验证](../verification/2026-10-14-answer-readability.md)，本次没有发布新版本。

上一版卡片外观、截图隐藏和输入区布局见 [简约横向卡片验证](../verification/2026-10-14-minimal-answer-card.md)。最新动态高度、X 关闭、边框与圆角见 [动态回答卡片验证](../verification/2026-10-14-dynamic-answer-card.md)；以上 640 × 400 等矩阵保留为上一版历史结果。

## 检查更新

- [ ] 在应用设置中增加「检查更新」入口。
- [ ] 显示当前版本、是否有新版本，并提供更新说明和下载入口。
- [ ] 检查失败时显示简短提示，允许重试。
- [ ] 验证更新后保留已有模型和手势设置。

## 1-ping 模式

开启后，在目标上按 **Alt + 鼠标左键单击** 即可触发，无需拖出轮盘。

- [ ] 增加 1-ping 模式开关，关闭时保持现有 Alt + 单击行为。
- [ ] 确定单击触发的默认任务，以及是否允许用户选择该任务。
- [ ] 以单击位置作为目标，沿用截图、回答和追问流程。
- [ ] 保留拖动轮盘选择意图的操作，验证单击与拖动能正确区分。
- [ ] 检查暂停状态、连续点击和与其他应用快捷操作冲突的情况。

## 烟花彩蛋

在 pingscreen 自身界面中 ping 时，仅在触发位置播放烟花动画。

- [ ] 增加烟花彩蛋，动画结束后自动消失。
- [ ] 彩蛋仅播放动画，不截图、不请求 AI、不创建新的回答会话。
- [ ] 验证软件内的正常操作，以及在其他应用中标点提问的流程。

## 验收

- 轮盘大小、回答字号和 1-ping 开关在重启后保留。
- 常见窗口大小和显示器缩放比例下，内容可读、操作准确。
- 完成后补充对应版本的变化与验证记录。
