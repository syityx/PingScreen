## 后续方向

优先验证光标附近的画面聚焦与图片用量优化。随后改善长回答的流畅度，并补充多显示器、高缩放比例和不同电脑上的使用验证。

回答字号、卡片精简、服务商预设与配置页优化纳入 0.1.7。另计划增加轮盘大小配置、检查更新、1-ping 单击触发模式，以及在软件自身界面中 ping 时仅播放烟花的彩蛋。

## 文档维护

- `changelog.md` 按版本记录已完成的主要变化，新版本放在最上方。
- `plans/` 按日期和主题保存计划，使用待办清单跟踪进度。
- `verification/` 按版本保存结果，区分已验证、待验证和已知限制。
- `media/` 保存 README 使用的演示图片。
- `design/brand/` 保留构建新 Logo 必需的源图；旧设计导出、草稿 Logo 与 Demo 归档仅在本地保留。

安装和使用说明见 [项目 README](../README.md)。
