## 后续方向

优先验证光标附近的画面聚焦与图片用量优化。随后改善长回答的流畅度，并补充多显示器、高缩放比例和不同电脑上的使用验证。

另计划增加轮盘大小配置、回答字号控制、检查更新、1-ping 单击触发模式，以及在软件自身界面中 ping 时仅播放烟花的彩蛋。
