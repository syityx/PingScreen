# pingscreen 版本变化

## 未发布 · 回答阅读体验

- 在“应用”设置加入回答字号滑块，默认 16px，支持 14–24px、步长 1px；自动保存、重启保留，并在下一次回答生效。
- 正文、列表、标题、代码和表格随字号协调调整，保留长回答滚动及代码、表格的局部横向滚动。
- 卡片改为宽 640px、初始高约 160px 的纯白布局，随回答增高，最高为实际宽度（默认 640px）；达到上限后正文滚动，输入区保持可见，同一会话不反复收缩。
- 左上角保留 Logo 和 PingScreen，右上角 X 可关闭会话并中止生成；采用 2px 浅灰边框与 20px 圆角，隐藏意图、自动任务提示及截图展示。
- 底部改为空白输入框与同一行右侧圆形向上箭头，保留键盘操作和生成时的停止图标；复制图标在悬停或聚焦时显示。
- 保留键盘发送/换行、截图上下文、复制、停止、失败重试等能力，复制结果在剪贴板操作完成后反馈，失败不会被误报为成功。

验证与待手测项目见 [回答阅读体验验证](verification/2026-10-14-answer-readability.md)。本次仅修改开发工作区，版本仍为 0.1.6，没有构建或发布新的安装包。

最新动态高度方案与验证见 [动态回答卡片验证](verification/2026-10-14-dynamic-answer-card.md)，替代 [上一版固定横向卡片](verification/2026-10-14-minimal-answer-card.md) 的固定比例与无关闭按钮方案。

## 0.1.6 · 正式版

- 使用用户选定的蓝色 P / ing 产品 Logo，更新界面品牌图形、应用与托盘图标、Windows 多尺寸图标和 README。
- 保存原始透明 PNG 与可重复执行的图标生成脚本；每次 GitHub 构建重新生成品牌图片并核对打包内容。
- 新增 GitHub CI 与正式标签自动发布，提供 Windows x64 安装程序、blockmap 和 SHA-256 校验文件。
- 整理公开源码与 README，排除本地配置、密钥、依赖、构建结果及过时设计素材，保留用户修改的产品标题与简化展示。
- 保留 lolPing 原作者版权与完整 MIT 声明，发布验证增加全部运行依赖和 Electron / Chromium 许可文件检查。

验证与发布方式见 [0.1.6 正式版验证记录](verification/0.1.6.md)。

## 0.1.5 · 正式版

- 将已确认的 0.1.4 UI Demo 整合进 Windows 正式安装版，移除正式版界面的 UI Demo 标识。
- 采用统一白色界面、原创图标和紧凑连续配置页，保留平滑滚动、轻度吸附与左侧定位；无顶部菜单、部分间大块留白或末尾空白。
- 手势、轮盘和开机启动修改立即保存，模型使用独立的「测试连接」与「保存」；测试不保存草稿，保存失败会提示并回退。
- 应用介绍仅保留版本与平台，保留 MIT 与原作者声明，底部 lolPing 项目名称可点击打开仓库。
- 正式版沿用 com.pingscreen.app 和原正式配置目录；Demo 继续保持独立身份和目录。
- 建立本地 Git 仓库，保留 v0.1.4-demo 基线与 v0.1.5 正式标签，排除依赖、构建产物与本地测试数据。

验证与安装包检查见 [0.1.5 正式版验证记录](verification/0.1.5.md)。

## 0.1.4 · UI Demo

- 移除顶部 File / Edit / View / Window 菜单栏。
- 配置页改为模型连接、手势、轮盘、应用四个连续滚动部分。
- 加入平滑导航与轻度滚动吸附；左侧随滚动高亮，点击可定位。
- 保留跨部分编辑的设置草稿，窄窗口可滚动到长内容底部。
- 底部显示 MIT 协议、基于 lolPing 与原作者版权声明。
- 去除末尾额外留白，滚动与导航最多到达真实内容底部。
- 各部分按内容自然高度连续排列，缩小标题、卡片与间距，去除部分之间撑满一屏的空白。
- 应用介绍仅保留版本和平台两行，删除重复的会话说明；底部 lolPing 项目名称可点击打开 GitHub 仓库。
- 手势、轮盘和开机启动修改立即保存，快速修改按序持久化；保存失败会提示并回退对应设置。
- 模型配置仅保留独立的「测试连接」和「保存」按钮；测试当前草稿，不自动保存，其他设置不会顺带保存模型草稿。
- 继续只发布免安装 Demo，沿用独立 Demo 设置目录。

验证结果见 [0.1.4 UI Demo 验证记录](verification/0.1.4-demo.md)。
