# pingscreen 版本变化

## 0.1.8 · 正式版

- 新增自定义轮盘，可调整功能顺序、显示项数，并配置自己的提示词和图标。
- 优化轮盘编辑体验，支持拖动排序、预览及未保存提醒。

发布检查见 [0.1.8 验证记录](verification/0.1.8.md)。

## 0.1.7 · 正式版

- 优化配置页布局和导航，让设置更清晰易用。
- 改进回答卡片，支持调整字号，提升长内容阅读体验。
- 新增常用模型服务商预设，支持分别保存连接配置。

发布检查见 [0.1.7 验证记录](verification/0.1.7.md)。

## 0.1.6 · 正式版

- 更新产品 Logo、应用图标和项目介绍。
- 完善正式版自动构建与发布，提供安装包和校验文件。

发布检查见 [0.1.6 验证记录](verification/0.1.6.md)。

## 0.1.5 · 正式版

- 推出 Windows 正式安装版，沿用已有正式版配置。
- 更新白色界面与设置页，优化配置保存体验。

发布检查见 [0.1.5 验证记录](verification/0.1.5.md)。

## 0.1.4 · UI Demo

- 精简配置页布局，优化分类导航和滚动体验。
- 完善配置草稿与保存反馈。

验证结果见 [0.1.4 UI Demo 验证记录](verification/0.1.4-demo.md)。

## 0.1.3 · UI Demo

- 更新设置页、轮盘和回答卡片的整体界面。
- 完善提问、停止、重试等交互，提供独立 Demo 体验。

验证结果见 [0.1.3 UI Demo 验证记录](verification/0.1.3-demo.md)。
